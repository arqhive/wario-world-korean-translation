# 와리오 월드 (GC) 한글 패치

*Wario World* (게임큐브, 일본판 `GWWJ01`) 비공식 한국어 팬 패치입니다.
일본판(『ワリオワールド』) 원문을 기준으로 번역했습니다.

**제작: arqhive** · **최신 버전: [v1.0f](../../releases/tag/v1.0f)**

- 메뉴, 옵션, 스테이지·보물 이름, 요정 도움말, 마늘 자판기, 오프닝 이야기, 엔딩, 세이브·오류 메시지, GBA 연결 안내를 한글화했습니다.
- 목표 안내판, 타이틀 로고, 메모리 카드 배너 그림을 한글화했습니다.
- 한글과 숫자·영문·기호를 G마켓 산스 Bold로 맞췄습니다.
- 원작에서도 영어인 문구(WARIO WORLD, 엔딩 크레디트 등)는 영어 그대로 두었습니다.
- **파일 단위 패처**라서 덤프마다 이미지 해시가 달라도 게임 파일만 같으면 적용됩니다.

> 이 저장소에는 **게임 데이터(디스크 이미지, 추출한 원문 대사, 원본 그래픽, 스크린샷)가 들어 있지 않습니다.**
> 패치를 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 디스크 이미지(`GWWJ01`, Rev 0). 북미판·유럽판에는 적용할 수 없습니다.
- Windows 10 이상(64비트). 따로 설치할 것은 없습니다.
- 빈 공간 약 1.5GB.

### 지원 형식

| 원본 | 결과 |
|---|---|
| ISO, GCM | ISO |
| RVZ, GCZ, CISO, NKit | 지원 안 함. Dolphin 등에서 ISO로 바꾼 뒤 적용 |

### 적용 방법

1. [릴리즈 페이지](../../releases/latest)에서 `GWWJ_KPatch_v<버전>.zip`을 받아 압축을 풉니다.
2. `WarioWorld_KO_Patcher.exe`를 실행하고 일본판 원본 이미지를 고릅니다.
3. 결과를 저장할 경로를 정하고 **한글 패치 적용**을 누릅니다. 원본은 바뀌지 않습니다.

명령줄로도 쓸 수 있습니다.

```
WarioWorld_KO_Patcher.exe --input "원본.iso" --output "한글.iso"
```

### 실행 환경

- **확인함**: Dolphin, Wii U Nintendont(USB Loader GX).

## 개발자용

- 번역문: [`translation/ko.json`](translation/ko.json)에 ID별 한국어 번역문만 들어 있습니다. `@`·`@P`는 줄바꿈, `@N`은 창 넘김, `@C….`는 글자 색 태그라 그대로 둡니다.
- 도구: [`tools/`](tools)에 분석·추출·글꼴·빌드·패처 도구 소스가 있습니다(Python 3.13, NumPy, Pillow).
- 일본어 원문 추출본, 그림 작업 파일, 작업 상태 기록은 게임 데이터이거나 작업용이라 넣지 않았습니다. 그래서 이 저장소만으로는 바로 빌드되지 않고, 원본 이미지에서 추출부터 다시 해야 합니다.
